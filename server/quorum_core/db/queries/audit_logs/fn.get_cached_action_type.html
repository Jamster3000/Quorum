Expand description

Retrieves the cached action type ID for a given log name, or creates it if it doesn’t exist.

This function checks the ACTION_TYPE_CACHE for the specified action_name. If it exists, it returns the cached RecordId. If not, it queries the database to find or create the action type and updates the cache accordingly.

§Arguments

  • db - A reference to the database connection.
  • action_name - The name of the action type to retrieve or create.

§Returns

A RecordId representing the action type ID associated with the given action_name.
