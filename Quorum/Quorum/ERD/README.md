# Entity Relationship Diagram
This directory contains the Entity Relationship Diagram (ERD) for this project.
The ERD visually represents the relationships between different entities in the database, helping to understand the structure and design of the database schema.

It's advised to use this ERD as a reference when working with the database, knowing how to access something and how an entity relates to another.

The ERD is a png image which also includes a basic colour key system to making it easier to find and identify entities quicker.

## Editing
Any editing that needs to be done to this ERD can be made using the `.drawio` file.

## Saving and exporting
When any changes have been made it's vital to save the changes and export.

**Save**: Save ths `.drawio` file to ensure that the ERD can be opened and edited with the same software in the future.
**Export**: Export the ERD as a '.png' file so it can be easily viewed without the software.

Please ensure that any changes are saved and exported.
