# Wireframes

This directory contains wireframes for the Quorum application.

For those that don't know, wireframes are a visual representation of the user interface of an application.
They are used to communicate the design and layout of the application to stakeholders, developers and designers.

---

## Wireframe Tools
For this I used my favourite tool that has always worked the best for wireframes, Microsoft PowerPoint (it's pratically the only thing it's useful for).

---

## Wireframes
The following are wireframes that have been created (see .png files or the PowerPoint file for the visual wireframes):

- Main Landing Page (Desktop view only) - This is basically the user dashboard for when the user is logged in and authenticated.
- Create Account (Desktop view only) - The page to allow the user to create an account.
- Login (Desktop view only) - The page to allow the user to login to their account.
- Settings (Desktop view only) - The page to allow the user to change their settings and preferences.
- Group Discovery (Desktop view only) - Shows the general layout of how users will search for and find groups to join.

- Group [text space] (Desktop view only) - This page shows the general layout of a text space, where uses send messages to each other in a group.
- Group [voice space] (Desktop view only) - This page shows the general layout of a voice space where uses talk verbally.
- Group [Gallery Viewing space] (Desktop view only) - This page shows the general layout of a gallery viewing space. This allows for people to upload and share images similar to an album.
- Group [Gallery Adding] (Desktop view only) - This page shows the general layout of a gallery adding space. This allows for people to upload images to the gallery.
- Group [IDE/notepad directory] (Desktop view only) - This pages shows the layout of how directories can be used in this space (proper name for this space is still in consideration)
- Group [IDE/notepad file] (Desktop view only) - This shows how editing and reading files can look
- Group [Project space to-do] (Desktop view only) - This shows the to-do project board.
- Group [project space Kanban] (Desktop view only) - This shows the kanban project board.
- Group [project space gantt chart] (Desktop view only) - This shows an example of how the gantt chart may look like.
- Group [Project space calendar] (Desktop view only) - This shows a basic example of how the calendar can look. Though the wireframe is harder to get a full calendar view into it, the product will have more space and easier to work with.
- Group [Project space table] (Desktop view only) - Shows a basic spreadsheet/table view which is more flexible to work with any type of project board.

---

## IMPORTANT NOTES

**COLOUR** - The colours used in the wireframes are not final and are just used for visual purposes.

**LAYOUT** - MY purpose for these wireframes are to get a general idea of where everything is layed out and where things are positioned. There might be additional changes as this is more of a draft which may not even come close to looking like the final product.
