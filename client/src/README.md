# Quorum Client Frontend

This directory contains the **Svelte-based frontend** for the Quorum client. It handles the UI, routing, and user interaction logic, communicating with the Tauri backend via Rust commands.

---

## Structure
   File/Folder       | Purpose                                                                                     |
 |-------------------|---------------------------------------------------------------------------------------------|
 | `lib/`            | Reusable Svelte components, utilities, and logic.                                           |
 | `routes/`         | Page routes for the app (e.g., `/home`, `/login`).                                          |
 | `app.css`         | Global styles for the application.                                                          |
 | `app.html`        | Root HTML template for the Svelte app.                                                      |
