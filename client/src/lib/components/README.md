# Components

This directory contains all **reusable Svelte components** for the Quorum client UI.

---

## Structure
   Folder      | Purpose                                                                 |
 |-------------|-------------------------------------------------------------------------|
 | `app/`      | **parent components** - for components that use other components        |
 | `ui/`       | **General UI components** (e.g., buttons, modals, inputs, cards).       |
